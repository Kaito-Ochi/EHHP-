TOP MISSION SERVICE ABOUT

真の自分と出会う場所。

共に高め会える仲間と出会う場所。

自分のポテンシャルを最大化させる場所。

それが「EHS」。

EHSは『人生を変える、学びの場。』です。

高い志を持った仲間と共に成長を目指し、夢を語り、後輩に背中を見せられる人になっていく。学び続けることが自己成長になると信じている人たちがいる場所です。

新卒採用が今後大きく変わろうとしています。新卒であれば誰でも良かった時代とは大きく変わり、スキルのある学生が重宝される時代に。だからこそ、早い時期に市場価値を高めておく必要があると考えています。私たちは意味のある「経験」を提供し、最大限の経験価値を提供できる場所で在り続けたいと思います。

FEATURE

EHSの特徴

FEATURES

01

経営者･政治家など各業界のプロフェッショナルから直接学べるプログラム

各業界の最前線で活躍する方々が、講師やメンターとして、受講生を応援。視野を広げ、視座を高める生きた学びのプログラムが充実。

02

プレゼン大会や事業創出等の限界突破に挑戦

学びのステージごとに用意された挑戦の場。結果よりも挑戦心を大事にする体験により社会の中心で活躍できる人間へと成長。

03

前を走る先輩がサポートするセンパイ制度

先生ではない、一歩先の学びに取り組むセンパイ達が学びをサポート。教えることが最大の学びとなる循環型学習。

PROGRAM

提供プログラム

PROGRAM

ワンランク上のキャリアを目指す大学生のためのハイキャリア育成ビジネスコース。ビジネスセンスを段階的に発掘・確立し、活躍を継続につなげていきます。

基礎コース

ビジネスで戦うための「思考体力」と「スタンス」を築く

コースのゴール

あらゆるビジネスの土台となる、普遍的なスキルとマインドセットを徹底的に鍛え、自走できる人材を目指す。

主な学習内容

  • 思考力の強化
    • ロジカル・シンキング / クリティカル・シンキング
    • ケーススタディを通じた実践的な問題解決演習
  • コミュニケーション能力の向上
    • プレゼンテーション（構成・資料作成）
    • ビジネスライティング（議事録・報告書・メール）
  • ビジネス基礎知識の習得
    • マーケティング / 会計・ファイナンス入門
    • ビジネスの全体像を捉えるための基礎知識
  • キャリアプランニング
    • 自己分析とキャリアデザインワークショップ
    • 多様な業界で活躍する社会人との座談会

実践コース

知識を価値に変える「事業創造力」と「リーダーシップ」を磨く

コースのゴール

基礎スキルを総動員し、リアルなビジネス課題に挑戦。チームを率いて成果を生み出す、真の実践力を養う。

主な学習内容

  • プロジェクト型学習（PBL）
    • 実在する企業への経営課題解決策の提案
    • ゼロからの新規事業立案プロジェクト
  • リーダーシップとチームマネジメント
    • チームの成果を最大化するファシリテーションスキルの実践
    • 多様なメンバーとの協働を通じたチームビルディング
  • プロフェッショナルによるメンタリング
    • 各業界の第一線で活躍するプロからの直接指導
    • プロジェクトやキャリアに関する個別フィードバック
  • 特別キャリア支援
    • 本プログラム限定の優良企業インターンシップへの参加機会
